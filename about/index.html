Welcome to shamiComposer, a shamisen notation editor. shamiComposer is free to use and the current features will be free forever. I might add features like cloud storage that would cost me real money, so I would probably need to charge a little at that point (max $5 a month, but I’m hoping for more like a couple of bucks a month).

I think it has most of the features you would expect, but definitely not all of them. It’s a work in progress…

Features

  • Unlimited editing and printing
  • Selectable time signature
  • Selectable tuning
  • Techniques: sukui, hajiki, suberi, uchi, suri
  • An optional fretboard display where you can see and hear the note for each position on the strings.
  • Components: I think this is an idea unique to this editor. Kamashi and triplets are treated as a single component. Kamashi is a fixed 4300 and triplets are a drop in, editable unit that fills the correct amount of time. These are troublesome in other editors because they don’t cleanly fit in standard timing.
  • Fixed and variable length measures. In fixed mode, every measure has the same width. In variable mode, measures will shrink and grow to fit their content, with a variable amount of padding.
  • Another unique feature, I think, is that shamiComposer tries to ensure that every measure is valid from a timing standpoint. Every beat must be accounted for, notes can’t overlap (other than chords), etc.
  • Simple backup to Google Drive. It’s not that fancy, but it does work.
  • A very crude playback mechanism. The sounds are pretty terrible and there is no support for techniques, but it does give you a vague sense of what a piece sounds like.

Future plans

  • Real cloud support with unlimited storage. As of right now, this is the only feature that would be behind a paywall.
  • Better sounds.
  • More flexible display of techniques and components (there’s more than one way to draw a kamashi and more than one name for it)
  • Better support for non-shamisen notation like repeats, etc.
  • Non-musical notation like attachable notes.

A little background

I have been noodling on a shamisen tab editor for years. I have at least four abandoned efforts in various states of completion. A while back I started on a Flutter (a way to build apps that work on multiple platforms, like Mac, Windows, and web) version, which showed a lot of promise, but Flutter for web was a little weak, and I didn’t want to get locked into native (Mac and Windows) versions. Plus life just kept getting in the way…

Then I met some new friends, Claude and Chappy (as he is known in Japan), who were a huge help in helping me actually get this thing over the finish line. Plus, Flutter reached a point of sophistication that I was comfortable shipping a web version (and only a web version, at least to start).
